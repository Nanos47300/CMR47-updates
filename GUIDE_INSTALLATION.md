# CMR47 · Guide d'installation pour les collègues

## Première installation (Android)
1. Ouvrir ce lien public : https://github.com/Nanos47300/CMR47-updates/releases/latest
2. Dans **Assets**, télécharger **CMR47-v....apk**.
3. Ouvrir le téléchargement et autoriser l'installation Android.
4. Ouvrir CMR47. Aucun compte GitHub n'est nécessaire.

## Mise à jour (déjà installé)
1. Dans CMR47 officielle : **Infos CMR47 → Rechercher une mise à jour**.
2. Confirmer la nouvelle version et accepter l'installation Android.
3. Si besoin, reprendre l'installation interrompue depuis le même écran.

**Ne jamais désinstaller l'application existante pour la mettre à jour.**
Les données non synchronisées risquent d'être perdues. En cas de refus Android, faire vérifier l'identifiant et la signature au responsable CMR47.

La diffusion est encore en phase de tests : **ne pas saisir de données professionnelles confidentielles** tant que la connexion personnelle et les autorisations serveur ne sont pas activées.

Le lien donne uniquement accès aux **versions officielles signées et publiées**, jamais aux compilations debug privées. Le fichier APK est réservé à Android. Les mises à jour ne sont pas automatiques.

**Lien permanent à transmettre :** https://github.com/Nanos47300/CMR47-updates/releases/latest
